# SKMedKART V2.0

Sri Krishna Medicals - Pennagaram pharmacy billing app.

## V2 features
- Bill / invoice number
- Multiple medicines per bill
- Automatic stock deduction when bill is saved
- Discount and GST %
- Customer name and phone
- WhatsApp bill sharing
- Print / Save as PDF
- Low-stock and expiry alerts
- Customer refill reminder
- Today and monthly sales reports
- SQLite database migration support

## Build configuration
- Android Gradle Plugin: 8.6.1
- Gradle: 8.7
- JDK: 17
- compileSdk / targetSdk: 35
- versionCode: 2
- versionName: 2.0

AGP 8.6.x is paired with Gradle 8.7. Do not change AGP to 8.7.x unless Gradle is also upgraded to at least 8.9.
